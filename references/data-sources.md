# 数据源手册

## 原则

1. **免 token 优先**：零配置可跑；付费源永远是可选项。
2. **可追溯 > 全面**：检索不到的数字不得写入报告。
3. **预取优先**：能用脚本 / 接口确定性获取的先预取，再交给模型分析。
4. **降级明确 + 来源分级**：脚本失败 → web 检索。web 数字分级引用：能定位到具体来源页面（交易所披露、官方公告、财经站点页面）并注明出处与日期的，视为可引用；仅来自搜索结果摘要、无法定位原始出处的，标注「未经核实」，只作方向性佐证，不得作为评级主论据。

## 行情（免费）

- **A股**：akshare（`pip install akshare`）。日线 `stock_zh_a_hist`（qfq 前复权）、实时快照 `stock_zh_a_spot_em`，另有财务 / 资金流 / 龙虎榜等接口。优先走 `scripts/fetch_quotes.py`。
- **美股 / 港股**：yfinance（`NVDA` / `0700.HK`）。
- **无 Python 环境**：web 检索行情（东财 / 新浪财经 / Yahoo Finance 页面），只引用页面可见数字并标注来源与日期。

## 基本面

- **A股**：akshare 财务接口，或巨潮资讯网 / 交易所公告检索；三表以官方披露口径为准。
- **美股**：yfinance 报表接口 / SEC EDGAR 检索。

## 新闻 / 宏观

- 个股公告与新闻：交易所披露页（巨潮 / 上交所 / 深交所 / 港交所披露易 / SEC EDGAR）+ web 检索。
- 宏观数据：FRED（美国）、国家统计局 / 央行（中国）、东财宏观频道。宏观论断必须带数据锚点。

## 情绪（预取优先）

- **A股**：雪球个股讨论热度、东财股吧发帖量与基调、集思录（转债 / ETF 情绪）；以 web 检索或接口预取样本，标注样本时间窗与数量。
- **美股**：自带 Bullish / Bearish 标签的社区源（如 StockTwits）。
- **警告**：社媒自由抓取已废弃——模型在 prompt 压力下容易幻觉引述不存在的帖子。只使用预取样本并标注样本量。

## 可选增强（需用户自备 token）

- Tushare Pro：环境变量 `TUSHARE_TOKEN`，覆盖更全的财务 / 资金流 / 筹码数据。
- 任何付费数据 API：按用户配置接入，接入后仍遵守可追溯原则。

## A股特化注意

- **T+1 与涨跌停**：不存在"当日买当日卖"；涨跌停会截断收益分布，分析涨停连板类标的时显式提示流动性风险。
- **ST / *ST 与北交所**：退市与流动性风险，报告必须显式提示。
- **量纲**：不同接口成交量 / 成交额单位不一致（手 / 股，元 / 千元 / 万元），写入报告前换算并注明。
- **复权**：技术分析一律用前复权（qfq）；不复权数据在分红除权日会出现假跳空。
- **龙虎榜 / 大宗交易**：作为资金流佐证，不单独构成评级论据。

# 方法论总纲（为什么这样设计）

> 来源：TradingAgents（Tauric Research, Apache-2.0, arXiv:2412.20138）方法论内化。本仓库是其 skill 形态实现，并附加纪律层；不 redistribut 原项目代码。

## 四个正交视角 + 两个辩论

信息底座 = 价格（技术）+ 公司（基本面）+ 世界（新闻/宏观）+ 人（情绪），四个视角互不冗余。结论不靠加权平均，而靠对立角色辩论后由裁判集中裁决——加权平均会掩盖"论据结构"，辩论会把分歧暴露成可裁决的命题。

## 双辩论结构：方向 vs 力度

| | 多空辩论 | 风控辩论 |
|---|---|---|
| 辩论对象 | 分析师报告（事实底座） | Trader 提案（具体方案） |
| 参与方 | Bull vs Bear | Conservative / Aggressive / Neutral |
| 核心矛盾 | 方向（做不做） | 力度（做多大） |
| 裁判 | Research Manager → ResearchPlan | Portfolio Manager → PortfolioDecision |
| 注入历史反思 | 否 | 是（只在最关键决策点注入） |

## 防幻觉三层防线

1. **预取优先**：能确定性获取的数据（行情/财务/情绪样本）先预取再注入，不让 LLM 自主找数。
2. **可追溯**：精确数字必须能对应工具输出或可核实来源；prompt guard——不得声称"历史验证 / 支撑位反弹"除非有数据支撑。
3. **废弃不可靠源**：社媒自由抓取曾因 prompt 压力下幻觉引述被废弃——情绪只使用带标签/可预取核实的来源，并标注样本量与时间窗。

## 集中化评级

5 档词汇单一来源（`references/rating.md`），所有决策 Agent 复用，禁止定义漂移；裁判强制决断：证据一边倒时不允许用 Hold 逃避。

## 延迟反思（本 skill 的纪律层增量）

决策后不立即复盘；T+5 个交易日把实际收益（raw/alpha）写回决策记忆，分层注入后续分析：同标的近 5 条全量、跨标的近 3 条仅反思。收益窗口需要时间，且反思不应污染当次分析状态。详见 `references/reflection.md`。

## 执行原则

1. **先辩论再裁决**：每个决策点避免单 Agent 偏见。
2. **工具隔离**：每阶段产出固化为报告字段，下游读报告不读过程消息（省 token 且防串味）。
3. **状态最小化**：单次分析内过程用完即弃；跨次分析只经决策记忆单向传递。
4. **结构化 + Markdown 双轨**：决策有固定 schema 字段（便于确定性解析），渲染保持人类可读。
